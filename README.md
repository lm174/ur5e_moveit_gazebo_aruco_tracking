# UR5e MoveIt Gazebo Aruco Tracking (ROS Noetic)
ROS Noetic simulation project for UR5e robot arm with MoveIt, Gazebo, Aruco marker detection and easy_handeye eye-in-hand calibration.

Features:
- UR5e Gazebo simulation + MoveIt motion planning
- Eye-in-hand monocular camera mounted on end-effector
- Aruco marker pose estimation
- easy_handeye hand-eye calibration
- Real-time marker tracking by UR5e manipulator

Environment: Ubuntu20.04 ROS Noetic.
See README_CN.md for full documentation.
